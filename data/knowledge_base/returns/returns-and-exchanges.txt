Harbor & Co. Return and Exchange Policy (Sample / Fictional)

Return window:
- Electronics sold by Harbor & Co. may be returned within 15 days of delivery.
- Electronics in this sample catalog include headphones, speakers, and cables.

Condition requirements:
- A defective item may be returned even if the original box has been opened.
- For a standard change-of-mind return, items must be unused and in resaleable condition.
- Returns requested after 15 days from delivery are not accepted unless the item is covered by warranty.

How to start a return:
- The customer provides the order id and the reason for return.
- Approved returns receive a prepaid return label by email in this sample process.

Exchanges:
- This sample policy prefers return-and-repurchase over direct swaps.
- If a customer wants a different product, complete an eligible return and place a new order.
- Do not invent a free exchange program that is not written here.

Edge case — opened but defective:
- Defective items can be returned inside the return window even if opened.
- Change-of-mind returns that are opened and not resaleable are not accepted.
